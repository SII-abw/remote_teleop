# 机械臂回零

参考现场 `/home/siinuc2/Evo-RL/reset.py` 实现。作业控制面板提供“从臂回零”“遥操臂回零”和“取消回零并保持”。每个回零按钮控制所选角色的左右双臂，目标包含六个关节及夹爪，均为 0。目标使用平台配置映射后的关节坐标。

回零按钮是明确的运动操作，点击并确认后临时获取目标臂的控制权，不需要先点击普通遥操的“使能”。仅在未使能、录制空闲、三端配置一致且当前硬件验收或现场测试条件允许时接受请求。回零期间不接受其他运动、录制开始或配置保存。完成或成功取消后回到未使能，不自动启动遥操或策略。故障、停止或失联不会自动重试。

“确认故障已排除并复位”仍只清除故障，不产生回零轨迹。3D 打印串口遥操臂的自动回零暂不启用。

## 可选 reset topic

从臂及遥操臂接入配置各有 `homing` 分组，保存在有效配置与自定义方案中，前端可编辑：

| 字段 | 含义 |
|---|---|
| `reset_topic` | 可选 `std_msgs/msg/Int32` 回零话题；留空走位置目标序列 |
| `reset_prepare_topic` | 可选准备模式清理话题，在回零开始前发送 `Int32(0)` |
| `reset_expected_subscribers` | 开始前须匹配的订阅者数量，双 EAI 默认 2 |
| `duration_seconds` | 位置目标序列的最短时间，默认 5 秒 |
| `timeout_seconds` | 整次回零超时，默认 120 秒 |
| `joint_tolerance` / `gripper_tolerance` | 实测零位容差，默认 0.05 rad / 0.01 夹爪控制单位 |
| `confirm_samples` | 连续归零确认次数，要求不同的新鲜反馈，默认 3 |
| `velocity_max` / `acceleration_max` | 位置目标序列的七维速度、加速度上限，按左右臂重复 |

接入设置需要保存并重启三端后生效；存在尚未重启应用的修改时拒绝回零。reset topic 的消息协议固定参考 EAI：`1` 开始归零，`0` 退出归零并保持。其他消息协议需要对应桥接，不能仅改话题名称就假定兼容。

已配置 reset topic 时，不会自动退回目标序列：先等待所需订阅者匹配，发送 `0` 清理残留状态，再发送 `1` 开始；依据实际关节反馈连续确认零位后发送 `0`，保持发布器存活，再次发送 `0` 退出。取消、失败或超时也尝试重复发送 `0`。退出发布器保留约 2 秒用于可靠投递。若无法退出，界面明确报错，需要检查驱动。广播话题会作用于其全部订阅者，不能把不同控制组误接到同一个广播话题。

已部署的现场 EAI 遥操臂使用 `/robot_reset` 和 `/robot_prepare`，只读确认两者均为 Int32、各有两个订阅者。现场 ARX 从臂不配置 reset topic，使用原有 `/left/ARX_joint_targets`、`/right/ARX_joint_targets`。

原生 reset 的运动轨迹和限速由驱动执行。位置序列的速度参数不会覆盖驱动内部速度；存在平台附加测试速度/加速度上限时，拒绝原生 reset，需清空 reset topic 使用受平台限制的目标序列。

## 无 reset topic 时的位置序列

读取完整的新鲜 14 维实测反馈后生成五次平滑曲线，沿当前姿态回到零位，首尾速度和加速度为零。根据距离、配置速度及加速度自动延长执行时间，与 `safety` 限额取较小值；调度停顿时限制轨迹推进量，避免恢复后跳跃。使用适配器已有位置目标接口，因此沿用关节名称、方向、偏移和 ROS domain 配置。

运动中持续检查新鲜状态、位置范围、跟踪误差、操作员连接和任务授权。未提供完整反馈、零位超出关节限位或不能在超时内完成时，不开始运动。完成必须由实测反馈确认，不能仅因最后一个目标已发送就宣称成功。取消时保留当前位置或最后有效目标，避免将零位作为停止指令；停止保持也不会回发超出关节范围的异常反馈。

## 验证与部署

单元测试使用假设备覆盖轨迹速度/加速度、调度停顿、双订阅者原生协议、连续反馈、取消退出、陈旧反馈、权限互斥和旧任务回包拒绝。`tests/homing_smoke.py` 在三个模拟进程中检查主从回零、使能期间拒绝、取消、停止、配置保存互斥和操作员失联。`tests/ros_contract.py` 在隔离 domain 218 使用假驱动验证真实 DDS 投递，包括两名原生 reset 订阅者均收到开始和退出。

本次没有触发真实机械臂回零。部署已备份代码和六份现场配置并重启平台三服务；核验状态为 DISARMED、录制 IDLE、无回零任务，三端配置一致且无待重启修改。已有接线、标定和安全开关保留。
